# Déploiement Git

Le dépôt utilise la branche principale main et des commits Conventional Commits.

Workflow local :
1. git clone https://github.com/Devmaes/afridelight.git
2. cd afridelight
3. flutter create . --platforms=android,ios,web
4. flutter pub get
5. flutter analyze
6. flutter test
7. flutter run

Conventions recommandées : feat:, fix:, docs:, test:, refactor:, chore:.
